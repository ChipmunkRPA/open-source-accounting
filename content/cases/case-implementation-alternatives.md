# Worked case: the same implementation fee, different missing facts

> **AI-assisted editorial draft — not professionally reviewed.** Original educational content, not authoritative guidance. **Primary ASC text was not accessed.** Paragraph references are verification tasks, not evidence that current authoritative wording was reviewed. Confirm the framework, reporting period, elections, and source versions before use. All company names and transactions in examples are fictional.

## Shared facts
A fictional supplier charges 60,000 for annual hosted access and 6,000 for implementation. The draft agreement includes both labels but no useful statement of work. The platform must not determine performance obligations from those labels alone.

## Scenario A: retained deliverable
Operations later describes a reusable migration package delivered to the customer. Ask whether the customer can benefit from that output, whether it is separately identifiable in the arrangement, and what integration or dependency remains. Retaining an output is evidence, not the full current distinctness analysis. [fasb-asc]

## Scenario B: internal activation
Operations instead describes supplier account setup that produces no separately transferred customer output. Ask which actual promises the fee relates to, when those promises are transferred, and whether additional upfront-fee or renewal analysis is relevant. Do not jump directly from “not distinct” to a recognition period without completing the remaining analysis.

## Required agent answer
Use parallel columns for contractual facts, operational evidence, possible accounting implication, current authority needing verification, and reviewer questions. State that the two scenarios support different investigations but are not completed accounting conclusions.

## Evaluation conditions
A useful answer requests the statement of work, avoids inventing an ASC quotation, separates allocation from timing, and identifies the primary-text gap. An answer that says implementation is always separate or always deferred fails the case regardless of fluency.
