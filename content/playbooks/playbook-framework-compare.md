# U.S. GAAP and IFRS issue comparison — Agent playbook

> **AI-assisted editorial draft — not professionally reviewed.** Original workflow guidance, not authoritative accounting advice. Primary ASC/other proprietary standard text is not bundled or directly verified. All scenarios are fictional. Confirm applicable authority, source permissions, and entity facts.

## Purpose and application status
This is an original procedure for the `framework_compare` Agent workflow. The code catalogue currently marks it **experimental / deployment-gated**. Publication of this playbook does not establish that the workflow, source coverage, or accounting conclusions have been professionally validated. Reading this playbook is free; executing new Agent work in the hosted product requires the annual Agent subscription.

## Required intake
Specific issue, entities, separate framework periods, access to each authoritative source, known elections and transition facts.

## Execution plan
Analyze each framework independently before comparing. Do not infer IFRS conclusions from a U.S. GAAP guide or vice versa. Use columns for scope, recognition, measurement, presentation, disclosures, and transition only where supported. Mark an entire comparison cell unavailable when its primary support is missing rather than manufacturing symmetry.

## Expected deliverable
Two-framework evidence table; verified similarities/differences; applicability conditions; explicit source gaps.

## Stop or qualify the answer
The initial pack has no IFRS standard corpus and no verified IFRS requirements. This playbook specifies a future workflow, not an IFRS analysis.

## Reviewer handoff
Each decisive difference needs valid support from both frameworks. Cross-framework work stays experimental until coverage and professional evaluation justify release.

## Data and rights boundaries
Use only the selected workspace and approved sources. Preserve citations and limitations in exported work. A subscription grants software access, not publisher rights. A source policy and a technical review are independent gates; this draft playbook is not automatically admitted to Agent evidence.
