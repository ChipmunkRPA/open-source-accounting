# Uploaded documents plus GAAP — Agent playbook

> **AI-assisted editorial draft — not professionally reviewed.** Original workflow guidance, not authoritative accounting advice. Primary ASC/other proprietary standard text is not bundled or directly verified. All scenarios are fictional. Confirm applicable authority, source permissions, and entity facts.

## Purpose and application status
This is an original procedure for the `document_gaap` Agent workflow. The code catalogue currently marks it **core / enabled by default**. Publication of this playbook does not establish that the workflow, source coverage, or accounting conclusions have been professionally validated. Reading this playbook is free; executing new Agent work in the hosted product requires the annual Agent subscription.

## Required intake
Authorized documents, selected versions, entity/framework/period, suspected issues, known amendments and side letters.

## Execution plan
Create a document inventory and ask which files form the complete agreement. Extract candidate terms with document/page/section locators. Have the user confirm critical facts instead of treating model extraction as confirmed. Map each issue to permitted requirements and original commentary. Keep “contract says” separate from “accounting interpretation suggests.” Identify both contradictory clauses and absent terms.

## Expected deliverable
Clause-to-criterion matrix; confirmed/unconfirmed facts; conditional treatments; missing-document list; evidence-linked memo.

## Stop or qualify the answer
Unreadable pages, scans with no extracted text, missing amendments, unclear licensing, or an incomplete standard. Exclude unsupported text and explain what could not be analyzed.

## Reviewer handoff
Reviewer samples extraction against the actual file, verifies complete contract scope, and checks whether each quoted passage may be used in the intended export.

## Data and rights boundaries
Use only the selected workspace and approved sources. Preserve citations and limitations in exported work. A subscription grants software access, not publisher rights. A source policy and a technical review are independent gates; this draft playbook is not automatically admitted to Agent evidence.
