# Challenge my memo — Agent playbook

> **AI-assisted editorial draft — not professionally reviewed.** Original workflow guidance, not authoritative accounting advice. Primary ASC/other proprietary standard text is not bundled or directly verified. All scenarios are fictional. Confirm applicable authority, source permissions, and entity facts.

## Purpose and application status
This is an original procedure for the `memo_review` Agent workflow. The code catalogue currently marks it **core / enabled by default**. Publication of this playbook does not establish that the workflow, source coverage, or accounting conclusions have been professionally validated. Reading this playbook is free; executing new Agent work in the hosted product requires the annual Agent subscription.

## Required intake
Memo revision, intended period, confirmed facts, evidence bibliography, questions the preparer wants challenged.

## Execution plan
Extract claims from the memo and trace them to the supplied evidence. Look for unsupported absolutes, missing exceptions, inconsistent dates, circular references, and factual assumptions presented as findings. Test an alternative fact pattern that would change the conclusion. Return proposed edits as tracked suggestions; do not silently overwrite the author’s work.

## Expected deliverable
Findings classified as unsupported, inconsistent, missing fact, outdated, calculation issue, or stylistic; evidence links; proposed wording; unresolved review checklist.

## Stop or qualify the answer
No underlying sources, critical unreadable exhibits, or a user instruction to remove justified limitations. State the limits of the critique.

## Reviewer handoff
The reviewer decides whether each finding is valid. A second model response is not an independent audit or professional opinion.

## Data and rights boundaries
Use only the selected workspace and approved sources. Preserve citations and limitations in exported work. A subscription grants software access, not publisher rights. A source policy and a technical review are independent gates; this draft playbook is not automatically admitted to Agent evidence.
