# Close issue and evidence pack — Agent playbook

> **AI-assisted editorial draft — not professionally reviewed.** Original workflow guidance, not authoritative accounting advice. Primary ASC/other proprietary standard text is not bundled or directly verified. All scenarios are fictional. Confirm applicable authority, source permissions, and entity facts.

## Purpose and application status
This is an original procedure for the `close_pack` Agent workflow. The code catalogue currently marks it **experimental / deployment-gated**. Publication of this playbook does not establish that the workflow, source coverage, or accounting conclusions have been professionally validated. Reading this playbook is free; executing new Agent work in the hosted product requires the annual Agent subscription.

## Required intake
Period, open issues, amounts, owners, dependencies, trial-balance references, proposed entries, review status.

## Execution plan
Create an issue register with one accountable owner per issue. Link evidence and distinguish confirmed amounts from estimates. Identify dependencies that prevent a conclusion. For possible errors, keep measurement, materiality, and correction as separate decisions. Prepare journal-balance checks but do not post entries or replace approval controls.

## Expected deliverable
Close issue register; conditional memo links; evidence gaps; dependencies; draft entry list; sign-off status.

## Stop or qualify the answer
Posting requests, stale evidence after an input change, or an attempt to close unresolved issues simply because a deadline arrived.

## Reviewer handoff
Controllers approve entries and conclusions in their actual systems. The workspace is a documentation tool, not the general ledger.

## Data and rights boundaries
Use only the selected workspace and approved sources. Preserve citations and limitations in exported work. A subscription grants software access, not publisher rights. A source policy and a technical review are independent gates; this draft playbook is not automatically admitted to Agent evidence.
