# SEC comment-response preparation — Agent playbook

> **AI-assisted editorial draft — not professionally reviewed.** Original workflow guidance, not authoritative accounting advice. All scenarios are fictional. Confirm applicable authority, source permissions, and entity facts.

## Purpose and application status
This is an original procedure for the `sec_response` Agent workflow. The code catalogue currently marks it **experimental / deployment-gated**. Publication of this playbook does not establish that the workflow, source coverage, or accounting conclusions have been professionally validated. Reading this playbook is free; executing new Agent work in the hosted product requires the annual Agent subscription.

## Required intake
Actual comment letter, filing section, prior correspondence, responsible owner, deadline supplied by user, substantiation materials.

## Execution plan
Parse each comment into distinct requests and link it to the filing text. Build an evidence file for each assertion in the proposed response. Flag contradictions between proposed commitments and current processes. Keep management representations and future commitments explicit, subject to approval. Draft responses without auto-submitting or implying regulator endorsement.

## Expected deliverable
Comment tracker; evidence checklist; draft response; proposed filing changes; approval and unresolved-items register.

## Stop or qualify the answer
Missing actual comment, invented regulator requests, or unsupported representations. Do not turn another issuer’s response into a presumed safe harbor.

## Reviewer handoff
Management and counsel review factual assertions, commitments, and filing changes. The platform does not communicate with the SEC or close the review process.

## Data and rights boundaries
Use only the selected workspace and approved sources. Preserve citations and limitations in exported work. A subscription grants software access, not publisher rights. A source policy and a technical review are independent gates; this draft playbook is not automatically admitted to Agent evidence.
