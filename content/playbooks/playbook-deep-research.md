# Deep research — Agent playbook

> **AI-assisted editorial draft — not professionally reviewed.** Original workflow guidance, not authoritative accounting advice. Primary ASC/other proprietary standard text is not bundled or directly verified. All scenarios are fictional. Confirm applicable authority, source permissions, and entity facts.

## Purpose and application status
This is an original procedure for the `deep_research` Agent workflow. The code catalogue currently marks it **core / enabled by default**. Publication of this playbook does not establish that the workflow, source coverage, or accounting conclusions have been professionally validated. Reading this playbook is free; executing new Agent work in the hosted product requires the annual Agent subscription.

## Required intake
Question; entity and reporting framework; reporting period; decisions already made; source access available.

## Execution plan
Write the exact issue as a question. Separate accounting questions from contractual/legal questions. Split the issue into propositions and identify the primary material required to test each one. Retrieve only permitted evidence and record paragraph and version. Search for exceptions and plausible contrary interpretations, not just language supporting the first answer. Reconcile facts against assumptions before drafting.

## Expected deliverable
A conditional conclusion; facts matrix; authority map; application; alternative treatments; unresolved evidence; source/version list.

## Stop or qualify the answer
The main criterion is accessible only through a secondary summary; essential facts conflict; source periods cannot be matched. Produce a research-gap statement rather than a fabricated definitive answer.

## Reviewer handoff
Reviewer verifies every decisive proposition against source text and signs the exact answer revision. A list of citations alone does not establish support.

## Data and rights boundaries
Use only the selected workspace and approved sources. Preserve citations and limitations in exported work. A subscription grants software access, not publisher rights. A source policy and a technical review are independent gates; this draft playbook is not automatically admitted to Agent evidence.
