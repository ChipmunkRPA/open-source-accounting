# Audit preparation pack — Agent playbook

> **AI-assisted editorial draft — not professionally reviewed.** Original workflow guidance, not authoritative accounting advice. All scenarios are fictional. Confirm applicable authority, source permissions, and entity facts.

## Purpose and application status
This is an original procedure for the `audit_prep` Agent workflow. The code catalogue currently marks it **experimental / deployment-gated**. Publication of this playbook does not establish that the workflow, source coverage, or accounting conclusions have been professionally validated. Reading this playbook is free; executing new Agent work in the hosted product requires the annual Agent subscription.

## Required intake
Engagement regime, audit area, assertions, risk assessment, period, processes, evidence owners, authorized source scope.

## Execution plan
Map risks to assertions and potential evidence. Distinguish management’s preparation tasks from the auditor’s independent decisions. Identify how evidence completeness, accuracy, provenance, and cutoff will be established. Draft procedures only as planning suggestions. Keep sample-size and reliance decisions unresolved unless independently supported.

## Expected deliverable
PBC request list; risk/assertion/evidence matrix; suggested procedures; evidence-quality checks; outstanding questions.

## Stop or qualify the answer
User asks the platform to assert that an audit is complete or that evidence is sufficient without an engagement-specific professional evaluation.

## Reviewer handoff
An authorized auditor decides scope, sufficiency, appropriateness, and conclusions. The model cannot certify an audit opinion.

## Data and rights boundaries
Use only the selected workspace and approved sources. Preserve citations and limitations in exported work. A subscription grants software access, not publisher rights. A source policy and a technical review are independent gates; this draft playbook is not automatically admitted to Agent evidence.

## Sources and verification

- [AS 1105 — Audit Evidence](https://pcaobus.org/oversight/standards/auditing-standards/details/AS1105) — Selected evidence quality and company-provided information provisions; version applicability must be checked.
- [AS 2201 — Integrated ICFR audit](https://pcaobus.org/oversight/standards/auditing-standards/details/AS2201) — Selected paragraphs .62–.70 and Appendix A examined. Apply the version for the engagement; no full standard is bundled.
