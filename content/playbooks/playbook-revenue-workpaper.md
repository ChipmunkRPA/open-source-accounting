# Revenue contract workpaper — Agent playbook

> **AI-assisted editorial draft — not professionally reviewed.** Original workflow guidance, not authoritative accounting advice. Primary ASC/other proprietary standard text is not bundled or directly verified. All scenarios are fictional. Confirm applicable authority, source permissions, and entity facts.

## Purpose and application status
This is an original procedure for the `revenue_workpaper` Agent workflow. The code catalogue currently marks it **experimental / deployment-gated**. Publication of this playbook does not establish that the workflow, source coverage, or accounting conclusions have been professionally validated. Reading this playbook is free; executing new Agent work in the hosted product requires the annual Agent subscription.

## Required intake
Executed contract, promises, standalone selling-price evidence, variable terms, modifications, transfer/usage evidence, reporting cutoff.

## Execution plan
Use the five-step evidence file. Distinguish billing from performance. Validate fixed and variable amounts before allocation. Apply the numerical allocation helper only after the relevant accounting assumptions are confirmed; it cannot decide whether promises are distinct. Produce timing scenarios if evidence does not yet establish recognition. Reconcile scenario totals to contract economics.

## Expected deliverable
Fact file; step-by-step issue assessment; relative-SSP calculation where appropriate; conditional recognition schedule; draft entries; evidence gaps.

## Stop or qualify the answer
Unverified performance obligations, unsupported standalone prices, unresolved variable consideration, or an exception to general allocation not evaluated.

## Reviewer handoff
Check contract completeness, allocation exceptions, recognition evidence, and amounts. Do not label a schedule GAAP-compliant because the arithmetic balances.

## Data and rights boundaries
Use only the selected workspace and approved sources. Preserve citations and limitations in exported work. A subscription grants software access, not publisher rights. A source policy and a technical review are independent gates; this draft playbook is not automatically admitted to Agent evidence.
