# Disclosure benchmarking — Agent playbook

> **AI-assisted editorial draft — not professionally reviewed.** Original workflow guidance, not authoritative accounting advice. All scenarios are fictional. Confirm applicable authority, source permissions, and entity facts.

## Purpose and application status
This is an original procedure for the `disclosure_benchmark` Agent workflow. The code catalogue currently marks it **experimental / deployment-gated**. Publication of this playbook does not establish that the workflow, source coverage, or accounting conclusions have been professionally validated. Reading this playbook is free; executing new Agent work in the hosted product requires the annual Agent subscription.

## Required intake
Issue, peer-selection rationale, fiscal periods, filing types, source access, approved acquisition route.

## Execution plan
Select peers by relevant facts rather than by popularity. Record CIK/accession and actual filing dates when filings are legitimately retrieved. Extract only permitted disclosure material with precise locators and third-party screening. Compare business conditions, accounting elections, definitions, and reporting periods. Explain why each example is or is not comparable.

## Expected deliverable
Peer-selection rationale; comparable-company matrix; disclosure examples; factual differences; source provenance.

## Stop or qualify the answer
No actual filings retrieved; stale filings represented as current; an inference that common practice constitutes approval. The initial starter pack contains no company filing corpus.

## Reviewer handoff
Validate peer facts and periods. Reuse permissions and access restrictions still apply even when a filing is publicly accessible.

## Data and rights boundaries
Use only the selected workspace and approved sources. Preserve citations and limitations in exported work. A subscription grants software access, not publisher rights. A source policy and a technical review are independent gates; this draft playbook is not automatically admitted to Agent evidence.
