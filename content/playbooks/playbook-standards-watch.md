# Opt-in standards impact watch — Agent playbook

> **AI-assisted editorial draft — not professionally reviewed.** Original workflow guidance, not authoritative accounting advice. Primary ASC/other proprietary standard text is not bundled or directly verified. All scenarios are fictional. Confirm applicable authority, source permissions, and entity facts.

## Purpose and application status
This is an original procedure for the `standards_watch` Agent workflow. The code catalogue currently marks it **experimental / deployment-gated**. Publication of this playbook does not establish that the workflow, source coverage, or accounting conclusions have been professionally validated. Reading this playbook is free; executing new Agent work in the hosted product requires the annual Agent subscription.

## Required intake
User-selected topics, reporting framework/period, permitted platform source scope, cadence, explicit consent.

## Execution plan
Compare newly approved source records with the prior check. Separate an announcement, exposure draft, final standard, and effective amendment. Produce an applicability checklist instead of an automatic policy change. Record why an item might matter and what has not been verified. Pause checks according to subscription/consent rules.

## Expected deliverable
In-app change notification; document/version link; possible affected workspaces; adoption questions; review deadline supplied or approved by user.

## Stop or qualify the answer
No unrestricted web monitoring or email delivery is implemented in the starting application. Never claim that “no new platform item” means no external regulatory change.

## Reviewer handoff
Reviewer confirms issuance status, effective dates, transition, and applicability before updating any accounting policy or memo.

## Data and rights boundaries
Use only the selected workspace and approved sources. Preserve citations and limitations in exported work. A subscription grants software access, not publisher rights. A source policy and a technical review are independent gates; this draft playbook is not automatically admitted to Agent evidence.
