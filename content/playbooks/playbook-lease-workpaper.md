> **AI-assisted editorial draft — not professionally reviewed.** Original workflow guidance, not authoritative accounting advice. ## Purpose and application status
This is an original procedure for the `lease_workpaper` Agent workflow. The code catalogue currently marks it **experimental / deployment-gated**. Publication of this playbook does not establish that the workflow, source coverage, or accounting conclusions have been professionally validated. Reading this playbook is free; executing new Agent work in the hosted product requires the annual Agent subscription.

## Required intake
Contract and amendments, identified asset, substitution terms, use decisions, term/options, payments, rate assumptions, commencement facts.

## Execution plan
Evaluate the arrangement’s characteristics before invoking the calculation helper. Keep accounting conclusions such as term, classification, and rate separate from the arithmetic engine. Confirm timing convention, payment frequency, escalation, incentives, and nonlease components. Build a basic fixed-payment schedule only within the helper’s supported input scope.

## Expected deliverable
Lease-question checklist; confirmed inputs; simple liability schedule; timing assumptions; unsupported-feature list; draft memo.

## Stop or qualify the answer
Variable payments, modifications, foreign exchange, or unusual options outside the tool’s supported calculation. A present-value calculation alone does not establish a lease or full Topic 842 compliance.

## Reviewer handoff
Independently recalculate and reconcile. Confirm commencement, payment timing, discount rate, and all excluded components before any operational use.
