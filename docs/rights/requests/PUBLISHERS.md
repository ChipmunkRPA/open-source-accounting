## Draft request text — UNSENT

We are developing Open Source Accounting, an open-source application with free general AI chat and public educational/source-reading pages. Hosted Agent operations cost US$89.99/year. The service is intended for public users and commercial professional workflows. A user subscription is separate from any source license. We have not approved a monthly plan, unlimited promise or usage allowance.

Please identify whether you can authorize each operation independently for the exact works, editions and territory agreed with us:

| Operation | Requested clarification | Current authorization |
|---|---|---|
| Acquisition | Approved API/feed/manual delivery, domains, redirects, identifiers and rate limits | None |
| Raw storage | Immutable original files, checksums, backup retention and deletion | None |
| Extraction | Text, tables, notes and exact locators; normalization/format changes | None |
| Normalized storage | Searchable derived passages and version history | None |
| Embeddings | Separate model/endpoint, private indexes, deletion and re-indexing | None |
| Model input | Public AI/RAG service; server-side Google Cloud transmission | None |
| Display | Public source reader versus authenticated licensed-seat access | None |
| Quotation | Per-answer and cumulative cross-query limits; required notices | None |
| Export | User memo/workpaper MD/DOCX/PDF and onward sharing | None |
| Public repository redistribution | Whether any samples/fixtures/source content may be redistributed; default excluded | None |
| Training/fine-tuning | Not planned or requested for activation; expressly excluded unless separately agreed | None |

Our requested generation model is `gemini-3.8-flash`; actual Cloud availability, endpoint, region, retention and costs are not yet verified. We will not substitute those facts or claim zero retention. Please identify permitted provider/region/retention constraints and whether your approval requires final architecture review. Embeddings require separate verification. No source content is used to train our own model.

Please specify work/edition/language/jurisdiction, availability and effective dates, scope exclusions, license evidence/contract reference, audience/workspace/seat entitlements, attribution and notices, modification/translation rules, fees, renewal/expiry, revocation, correction triggers, raw/derived deletion and any audit/reporting obligations. A general subscription, public download or temporary cache will not be treated as operation-specific permission.

We can keep the product reference-only if any requested use is unavailable. Please distinguish permission to link independently maintained identifiers from permission to acquire or process the underlying text. This draft is not an acceptance, purchase order or representation of professional review.
