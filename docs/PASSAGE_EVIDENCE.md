# Exact intake passage evidence

Issue #25/#24, parent #5. `intake-passage-evidence-1` extends general source retrieval to retained intake locators, replacing generic “Section 1” labels for non-spreadsheet staged source passages. It applies across source families and parser types that use the immutable intake pipeline. Existing SEC Core and spreadsheet-specific paths remain separate.

A packet binds the staged source ID/version/policy version, full staged-body hash, selected text hash, exact source locator, parser version, artifact/extraction IDs and extraction hash, passage index, parent binding and available PDF/XML/annual-CFR/recovery provenance. Source provenance hashes cover all the included intake metadata. The retained artifact and parser/review records remain the authority for provenance; constructing a packet grants no rights or professional approval.

Ranges use **zero-based, end-exclusive Unicode character offsets in the exact staged passage**. Display citations use one-based inclusive characters appended to the original locator. These are not byte offsets, grapheme counts, raw PDF character positions or a reconstruction of missing printed-page labels. Paragraph splitting retains blank-line separators in absolute-offset accounting. Long paragraphs divide into at most 3,000-character evidence units; repeated text cannot move the selected occurrence without changing its offset/hash binding.

Runtime checks reproduce the packet and require exact text, locator, range and hash equality before model/output access. Changed provenance, forged citation labels, missing packets and changed source bodies fail closed. A stored source whose full text no longer matches its staged content hash cannot produce a new packet. Existing parser, technical, applicability, operation, workspace and output gates continue to apply independently.

Historical general intake evidence lacking this exact context is withheld for regeneration. It is not silently backfilled or presented as newly reviewed evidence. Reference-only records containing no body remain references. Non-intake original-library evidence, private documents, SEC Core and spreadsheet evidence retain their existing contracts; this change does not assert that every legacy citation type has received new provenance.

Context is bounded to 16,000 serialized bytes. Oversized optional provenance details are explicitly omitted while their exact digest remains bound. An oversized locator/core packet is rejected, never truncated into an apparently exact citation. A selected passage does not establish whole-document acquisition, complete definitions/exceptions, historical applicability or professional support for a claim.

Verification uses original synthetic passages, immutable intake/review test fixtures and mock Agent execution. It covers multiple blank-line forms, Unicode, 3,000-character boundaries, PDF/DOCX/HTML/XML locator preservation, body/locator/hash/offset/context tampering, oversized metadata and a saved-export gate. These fixtures and simulated reviewers are not real source acquisitions or independent accounting reviews. See progress.md for observed commands, current results and remaining gates.
