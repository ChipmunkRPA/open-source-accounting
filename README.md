# open-source-accounting

An accounting and auditing research application and original educational library for Google Cloud.

**Publication status:** the v0.6 source/content release is prepared locally, but the complete source import into this repository has not yet been verified. Do not treat transport staging files as runnable source. See [publication status](PUBLICATION_STATUS.md) and [progress](progress.md).

## Product

- Free general AI chat and public educational content.
- Hosted Agent subscription configured at **US$89.99/year** for deep research, document-assisted GAAP analysis, memo writing, comparisons, and structured workpapers.
- Preferred generation model: Gemini 3.8 Flash; the development default is a clearly labeled mock provider.
- Source permissions, claim/evidence relationships, versioned memos, and technical-review gates.
- Mandatory verified-email plus TOTP (Google Authenticator compatible) **or** SMS second-factor checks for authenticated application access; public learning pages remain accessible without signing in.

## Prepared content pack

63 original content items: 28 research guides, 8 worked cases, 9 templates, 16 Agent playbooks, and 2 study-question guides containing 58 structured questions. The pack includes 26 source/license reference records. All new material is AI-assisted editorial draft content, not independently approved accounting guidance. No proprietary accounting-standard corpus is included.

## Release limitations

The full local release includes readme.md, a detailed generated progress.md inventory, setup scripts, tests, and Google Cloud MFA instructions. Local validation does not establish live Cloud deployment, real TOTP/SMS operation, payment operation, or professional accounting accuracy. A complete production Firebase SDK build and live integration tests remain required.
